# A股月频截面多因子研究

这是项目重新清洗数据并完整复跑后的正式第一版。仓库只保留当前历史结果最好的稳定实现；低换手、残差目标、成本感知组合和其他未超过本版本的实验已从工作版本移除，其研究记录仍可在 Git 历史中追溯。

项目研究的问题是：只使用月末已经知道的信息，能否预测股票下一月在所属行业内的相对收益排名。策略不使用大盘择时，不把数据清洗当作 Alpha，也不把行业中性多空诊断组合包装成可直接交易的 A 股组合。

## 1. 研究流程

```text
CSMAR原始压缩数据
    ↓
月度行情、估值、财务公告、行业和证券状态合并
    ↓
data_cleaning.py 统一清洗与状态过滤
    ↓
普通多因子 Ridge 基线
    ↓
仅在历史验证期确有增量时启用 TabM/相似样本增量
    ↓
多头组合与行业中性多空诊断
    ↓
交易成本、分阶段、Bootstrap 和容量压力测试
```

正式输出来自以下三个入口：

- `quant_project.py`：从原始压缩文件重建月度面板和透明多因子基线；
- `advanced_quant.py`：清洗后执行最长84个月滚动训练、12个月历史验证和每3个月重估；
- `advanced_robustness.py`：生成成本、年度、分阶段和区块Bootstrap结果。

## 2. 数据清洗

`clean_monthly_panel` 在任何回归或机器学习之前统一执行：

- 股票代码补齐为六位并按股票—月份去重；
- 月收益限制在 `[-95%, 300%]`，同时保留异常标记；
- 成交额、市值必须为正；
- 年化波动率、非流动性和最大日收益必须落在预设合理范围；
- PE、PB、PS只保留正且不过度极端的值；
- ROA、ROE、毛利率、现金转化率和资产负债率执行经济范围检查；
- 财务数据只能在公告日以后使用，超过370天的陈旧财务数据失效；
- 剔除ST/特殊处理状态和非正常上市状态；
- 回归输入在月度行业截面内缩尾、排序和标准化。

本次实际复跑共读取564,728条股票月记录，其中408,337条进入最终合格样本，占72.31%。主要清洗记录：

| 检查项 | 影响记录 | 占比 |
|---|---:|---:|
| 收益异常 | 394 | 0.07% |
| 市场数据无效 | 2,309 | 0.41% |
| 估值字段无效 | 141,185 | 25.00% |
| 财务字段缺失或无效 | 247,710 | 43.86% |
| ST或特殊处理 | 15,981 | 2.83% |
| 非正常上市状态 | 277 | 0.05% |

无效估值或财务字段不会用全样本均值伪造；模型使用训练期内的中位数和标准化参数处理允许缺失的特征。

## 3. 时间边界与防止未来函数

- 原始面板：2014-01至2025-12；
- 因子方向形成期：2014-01至2017-12；
- 样本外信号：2018-01至2025-11；
- 对应实现收益：2018-02至2025-12，共95个月；
- 训练窗口：最长84个月；
- 验证窗口：每次训练样本末尾12个月；
- 模型重估：每3个月一次；
- 财务特征：按真实公告日向后匹配；
- 标准化、缺失值处理和模型拟合：只使用预测月份以前的数据；
- 标签：预测下一月股票在当月所属行业内的收益分位数减0.5。

每次重估的训练起止月、最晚标签实现月和预测月写入`output/advanced_leakage_audit.csv`。如果最晚训练标签的实现时间晚于预测月，程序会直接抛出异常而不是继续生成结果。本次全部32个重估点均通过。

2018—2025已经被反复查看，不能再称为完全未见样本。真正冻结配置后的前向验证必须从2026年以后开始。

## 4. 因子与模型

现有因子覆盖价值、盈利质量、风险、流动性和价格行为，包括：

- 盈利收益率、账面市值比、销售市值比；
- ROE、ROA、毛利率、现金转化和盈利改善；
- 低波动、下行稳定性、低换手和极端收益规避；
- 1个月、3个月、6个月和12-1个月反转；
- 市值稳定性、非流动性溢价和波动调整后反转。

Ridge是可审计的主信号。TabM与历史相似样本检索只有在当次历史验证IC相对Ridge提高至少预设门槛时才允许进入组合。完整样本中非线性模型只在25%的重估点通过准入，最终平均IC反而比纯Ridge低0.0039，因此不能解释为稳定的机器学习增量。

## 5. 组合定义

### 多头研究组合

- 在全部合格股票中持有预测分数最高的10%；
- 等权；
- 已有股票跌出前15%后才退出，以减少不必要交易；
- 默认单边成本20bp；
- 不使用市场择时。

这是月频可交易近似，尚未模拟涨跌停排队、逐笔冲击和真实订单执行。

### 行业中性多空诊断

- 只使用至少10只合格股票的行业；
- 每个行业等资本；
- 行业内分别持有预测最高10%与最低10%；
- 多头、空头两侧独立按真实权重变化计算换手。

该组合只用于检验截面排序能力。数据没有历史融券可得性、借券费用和挤兑风险，因此它不是可直接实盘的A股多空策略。

## 6. 完整复跑结果

默认成本为20bp，风险无风险利率按0处理。

| 序列 | 年化收益 | 年化波动 | Sharpe | 最大回撤 | 月均换手 | 月数 |
|---|---:|---:|---:|---:|---:|---:|
| 多头组合 | 10.69% | 18.92% | 0.565 | -25.38% | 34.86% | 95 |
| 行业中性多空诊断 | 20.62% | 15.83% | 1.302 | -21.93% | 113.17% | 93 |
| 沪深300 | 1.01% | 18.39% | 0.055 | -39.92% | — | 95 |

截面诊断：

| 指标 | 结果 |
|---|---:|
| 平均月度Rank IC | 0.1171 |
| 年化ICIR | 3.071 |
| 正IC月份比例 | 87.37% |
| 十分组单调性Spearman | 0.952 |
| 多空月收益t值 | 3.54 |

### 成本压力

| 组合 | 20bp Sharpe | 50bp Sharpe | 100bp Sharpe |
|---|---:|---:|---:|
| 多头组合 | 0.565 | 0.492 | 0.373 |
| 行业中性多空诊断 | 1.302 | 1.000 | 0.521 |

### 分阶段表现

| 阶段 | 多头Sharpe | 多空诊断Sharpe |
|---|---:|---:|
| 2018—2021 | 0.502 | 1.559 |
| 2022—2025 | 0.625 | 1.123 |

结论必须冷静理解：数据中存在稳定的行业内截面排序信号，但多头Sharpe 0.565仍未达到独立策略的可投门槛；多空诊断虽然更强，却有113.17%的月均换手且没有融券约束，只能视为Alpha研究上界。

## 7. 运行方法

建议在独立环境中运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe quant_project.py --start 2014-01-01 --end 2025-12-31
.\.venv\Scripts\python.exe advanced_quant.py --start 2018-01-01
.\.venv\Scripts\python.exe advanced_robustness.py
.\.venv\Scripts\python.exe -m unittest -q test_data_cleaning.py
.\.venv\Scripts\python.exe -m unittest -q test_advanced_quant.py
```

原始数据受许可限制，不上传GitHub。运行前需把项目所需CSMAR压缩文件放入`data/`目录；代码不会自动从互联网下载或虚构缺失字段。

## 8. 正式输出

- `output/monthly_panel.csv.gz`：重新清洗前的统一月度原始面板，本地生成且不提交；
- `output/data_quality_report.csv`：清洗规则实际影响记录；
- `output/backtest_monthly.csv`、`output/metrics.csv`：透明多因子基线；
- `output/advanced_backtest.csv`：第一版逐月收益、换手、净值和IC；
- `output/advanced_metrics.csv`：核心组合汇总；
- `output/alpha_diagnostics.csv`：Rank IC、ICIR、分组单调性和t值；
- `output/advanced_model_log.csv`：每次重估的验证结果和模型权重；
- `output/advanced_leakage_audit.csv`：训练标签实现月与预测月的未来函数检查；
- `output/linear_factor_coefficients.csv`：Ridge系数历史；
- `output/decile_returns.csv`：行业内十分组收益；
- `output/advanced_cost_stress.csv`：0至200bp成本压力；
- `output/advanced_subperiod.csv`：分阶段表现；
- `output/advanced_annual.csv`、`output/advanced_bootstrap.csv`：年度和区块Bootstrap；
- `output/capacity_analysis.csv`：不同资金规模的5日ADV参与率代理。

## 9. 研究限制

本项目仍缺少逐笔/订单簿数据、涨跌停排队成交、真实融券池与借券费、历史指数成分权重、正式风险模型和实盘订单回报。容量计算只是流动性代理，不是真实市场冲击函数。所有结果均为历史研究结果，不构成投资建议，也不代表未来收益。
